# trimbolt

Trim CSV/TSV bolt tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/trimbolt/

## Install / run

```bash
git clone https://github.com/theworker02/trimbolt.git
cd trimbolt
node src/cli.js
node --test
```
